# Stack-ADT-Expression-conversion
Implementation of stack ADT using a singly linked list for converting expression into postfix &amp; prefix expression.
## Description
This project implements Stack as an Abstract Data Type (ADT)
using a Singly Linked List.

The program converts an infix expression into:
- Postfix expression
- Prefix expression

## Features
- Stack ADT implementation
- Singly Linked List
- Push operation
- Pop operation
- Peek operation
- Infix to Postfix conversion
- Infix to Prefix conversion
- Operator precedence handling
- Parentheses handling
- Dynamic memory management

## Technologies
- C++
- Data Structures
- Stack
- Singly Linked List

## Example
Infix   : (A+B)*C-D
Postfix : AB+C*D-
Prefix  : -*+ABCD
